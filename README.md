Descrição do Projeto
Este repositório contém o código e a documentação para a implantação automatizada de uma API de inteligência artificial pronta para produção. O projeto utiliza uma abordagem multi-cloud: a infraestrutura de computação, segurança e rede é hospedada na AWS, enquanto a inteligência de processamento de linguagem natural consome os modelos generativos da Google Cloud (Vertex AI / Gemini API).

Toda a infraestrutura é provisionada como código (IaC) utilizando o Terraform, garantindo a portabilidade e a automação do ambiente.
